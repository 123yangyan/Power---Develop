# Polar BLE SDK 8.0.0 使用说明

> 本文档面向初学者，帮助你快速理解 **Polar BLE SDK** 是什么、能做什么、以及如何在自己的 App 中使用它。  
> 官方英文文档见 [README.md](./README.md)。

---

## 一、项目是什么？

**Polar BLE SDK** 是 Polar（博能）官方提供的 **蓝牙低功耗（BLE）开发工具包**，用于在 **Android** 和 **iOS** 应用中连接 Polar 传感器/手表，并获取生理与运动数据。

你可以用它实现：

| 能力 | 说明 |
|------|------|
| 实时心率 | 心率（BPM）+ RR 间期（毫秒） |
| 心电 ECG | 微伏级心电波形（如 H10，130Hz） |
| 加速度计 ACC | 三轴加速度（25/50/100/200Hz） |
| 光学心率 PPG | 光电容积脉搏波 |
| 陀螺仪 / 磁力计 / 气压等 | 视设备型号而定 |
| 离线录制 | 数据先存到设备内存，之后再同步 |
| 手表数据 | 睡眠、活动、训练记录、表盘配置等 |
| 设备管理 | 电量、固件升级、时间同步、恢复出厂等 |

**重要说明：**

- 本 SDK **只支持 Android / iOS 原生开发**，没有 Python / Web 绑定。
- 异步编程模型：
  - **Android**：Kotlin Coroutines + Flow（部分历史接口仍兼容 RxJava3）
  - **iOS 8.0**：已从 RxSwift **迁移到 Swift Concurrency**（`async/await`、`AsyncThrowingStream`）

## 三、核心架构（读懂代码的关键）

### 3.1 入口：`PolarBleApi`

所有功能都通过 **`PolarBleApi`** 这一个入口类访问。创建实例时，你需要声明要用哪些 **Feature（功能模块）**——只启用需要的功能，可以节省资源。

```kotlin
// Android 示例：创建 SDK 实例
val api = PolarBleApiDefaultImpl.defaultImplementation(
    applicationContext,
    setOf(
        PolarBleApi.PolarBleSdkFeature.FEATURE_HR,                    // 心率
        PolarBleApi.PolarBleSdkFeature.FEATURE_POLAR_ONLINE_STREAMING, // 在线流式数据
        PolarBleApi.PolarBleSdkFeature.FEATURE_BATTERY_INFO            // 电量
        // 只加你真正需要的功能即可
    )
)
```

### 3.2 Feature 一览

| Feature 常量 | 作用 |
|-------------|------|
| `FEATURE_HR` | 标准 BLE 心率服务 |
| `FEATURE_DEVICE_INFO` | 设备软硬件信息 |
| `FEATURE_BATTERY_INFO` | 电量与充电状态 |
| `FEATURE_POLAR_ONLINE_STREAMING` | ECG / ACC / PPG / PPI 等实时流 |
| `FEATURE_POLAR_OFFLINE_RECORDING` | 设备端离线录制 |
| `FEATURE_POLAR_H10_EXERCISE_RECORDING` | H10 内置运动记录 |
| `FEATURE_POLAR_OFFLINE_EXERCISE_V2` | 新一代离线运动记录 |
| `FEATURE_POLAR_SDK_MODE` | SDK 模式（更高采样率） |
| `FEATURE_POLAR_DEVICE_TIME_SETUP` | 设备时间同步 |
| `FEATURE_POLAR_FIRMWARE_UPDATE` | OTA 固件升级 |
| `FEATURE_POLAR_ACTIVITY_DATA` | 活动数据（步数、卡路里等） |
| `FEATURE_POLAR_SLEEP_DATA` | 睡眠数据 |
| `FEATURE_POLAR_TRAINING_DATA` | 训练/运动会话 |
| `FEATURE_POLAR_DEVICE_CONTROL` | 恢复出厂、首次配置等 |
| `FEATURE_WATCH_FACES_CONFIGURATION` | 手表表盘配置 |

### 3.3 典型工作流程

```
┌─────────────┐    扫描/连接     ┌──────────────┐    Feature Ready    ┌─────────────┐
│  初始化 API  │ ──────────────> │  BLE 已连接   │ ─────────────────> │  调用具体功能 │
└─────────────┘                 └──────────────┘                    └─────────────┘
       │                               │                                    │
       │  1. defaultImplementation()   │  3. bleSdkFeatureReady 回调        │  4. startHrStreaming()
       │  2. setApiCallback()          │     确认功能可用后再调用              │     startEcgStreaming() 等
       └───────────────────────────────┴────────────────────────────────────┘
```

**关键原则：**

1. 先连接设备（`connectToDevice` / `autoConnectToDevice` / `searchForDevice`）
2. 等待 `bleSdkFeatureReady` 回调，确认对应 Feature 已就绪
3. 再调用具体 API（如 `startHrStreaming`）
4. App 退出时调用 `api.shutDown()` 释放资源

### 3.4 两种数据获取模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **在线流（Online Streaming）** | 通过 BLE 实时推送数据 | 实时心率图、ECG 波形显示 |
| **离线录制（Offline Recording）** | 数据写入设备内存，之后批量读取 | 长时间采集、断连后补传 |

### 3.5 SDK 模式（进阶）

启用 **SDK Mode** 后，设备会提供 **更高采样率、更灵活的传感器参数**，但会 **关闭设备内置算法**（心率、RR、活动、睡眠等自动计算全部失效）。

- 开启：`startSdkMode()`
- 关闭：`stopSdkMode()` 或关机
- 详见：[documentation/SdkModeExplained.md](./documentation/SdkModeExplained.md)

## 六、快速开始

### 6.1 Android 集成

#### 步骤 1：添加依赖

在 `build.gradle` 中加入 JitPack 仓库和 SDK：

```gradle
repositories {
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.polarofficial:polar-ble-sdk:8.0.0'
    implementation "org.jetbrains.kotlinx:kotlinx-coroutines-core:1.10.2"
    implementation "org.jetbrains.kotlinx:kotlinx-coroutines-rx3:1.10.2"
}
```

> 本仓库自带的示例 App 也可使用本地 AAR：  
> `examples/example-android/polar-sensor-data-collector/polarBleSdk/polar-ble-sdk.aar`

#### 步骤 2：声明蓝牙权限（AndroidManifest.xml）

```xml
<!-- Android 12+ 扫描 -->
<uses-permission
    android:name="android.permission.BLUETOOTH_SCAN"
    android:usesPermissionFlags="neverForLocation"
    tools:targetApi="s" />
<!-- Android 12+ 连接 -->
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
<!-- Android 11 及以下需要定位权限用于扫描 -->
<uses-permission
    android:name="android.permission.ACCESS_FINE_LOCATION"
    android:maxSdkVersion="30" />
<!-- 固件升级需要网络 -->
<uses-permission android:name="android.permission.INTERNET" />
```

#### 步骤 3：运行时申请权限

```kotlin
// 根据 Android 版本申请不同权限组合
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
    requestPermissions(
        arrayOf(
            Manifest.permission.BLUETOOTH_SCAN,
            Manifest.permission.BLUETOOTH_CONNECT
        ),
        PERMISSION_REQUEST_CODE
    )
} else if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
    requestPermissions(
        arrayOf(Manifest.permission.ACCESS_FINE_LOCATION),
        PERMISSION_REQUEST_CODE
    )
}
```

#### 步骤 4：最小可运行示例（心率）

```kotlin
class MainActivity : AppCompatActivity() {

    // 创建 API，只启用心率功能
    private val api = PolarBleApiDefaultImpl.defaultImplementation(
        applicationContext,
        setOf(PolarBleApi.PolarBleSdkFeature.FEATURE_HR)
    )

    // 用于管理协程（Android 8.0 推荐用 lifecycleScope）
    private val scope = CoroutineScope(Dispatchers.Main + SupervisorJob())

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // 注册连接状态等回调
        api.setApiCallback(object : PolarBleApiCallback() {
            override fun deviceConnected(polarDeviceInfo: PolarDeviceInfo) {
                Log.d("Polar", "已连接: ${polarDeviceInfo.deviceId}")
            }

            override fun bleSdkFeatureReady(
                identifier: String,
                feature: PolarBleApi.PolarBleSdkFeature
            ) {
                // Feature 就绪后才能开始采集
                if (feature == PolarBleApi.PolarBleSdkFeature.FEATURE_HR) {
                    startHeartRate(identifier)
                }
            }
        })

        // 连接设备：deviceId 印在传感器背面，如 "0A3BA92B"
        api.connectToDevice("你的设备ID")
    }

    private fun startHeartRate(deviceId: String) {
        scope.launch {
            // startHrStreaming 返回 Flow，用 collect 持续接收数据
            api.startHrStreaming(deviceId).collect { hrData ->
                for (sample in hrData.samples) {
                    Log.d("Polar", "心率: ${sample.hr} BPM, RR: ${sample.rrsMs}")
                }
            }
        }
    }

    override fun onDestroy() {
        super.onDestroy()
        api.shutDown()  // 必须释放 SDK 资源
        scope.cancel()
    }
}
```

#### 连接设备的三种方式

| 方法 | 说明 |
|------|------|
| `connectToDevice(deviceId)` | 直连已知设备 ID |
| `autoConnectToDevice(rssi, ...)` | 按信号强度自动连接附近设备 |
| `searchForDevice()` | 扫描并选择设备 |

**Swift Package Manager（推荐，8.0）：**

或在 Xcode → File → Add Package Dependencies 添加上述地址。

> 若你从旧版迁移，参考 [MigrationGuide8.0.0-iOS.md](./documentation/MigrationGuide8.0.0-iOS.md)。

#### 步骤 2：配置 Info.plist

- 添加 `NSBluetoothAlwaysUsageDescription`（蓝牙使用说明）
- 在 Target → Signing & Capabilities 中启用 **Background Modes → Uses Bluetooth LE accessories**

#### 步骤 3：最小可运行示例（心率，Swift Concurrency）

```swift
import PolarBleSdk

class MyViewController: UIViewController,
    PolarBleApiObserver,
    PolarBleApiPowerStateObserver,
    PolarBleApiDeviceFeaturesObserver {

    // 创建 API，只启用心率
    var api = PolarBleApiDefaultImpl.polarImplementation(
        DispatchQueue.main,
        features: [.feature_hr]
    )

    let deviceId = "0A3BA92B"  // 替换为你的设备 ID
    var hrTask: Task<Void, Never>?  // 用于取消心率采集任务

    override func viewDidLoad() {
        super.viewDidLoad()
        api.observer = self
        api.powerStateObserver = self
        api.deviceFeaturesObserver = self
        api.connectToDevice(deviceId)
    }

    // Feature 就绪回调
    func bleSdkFeatureReady(_ identifier: String, feature: PolarBleSdkFeature) {
        if feature == .feature_hr {
            hrTask = Task {
                do {
                    // 8.0：使用 async stream 接收心率数据
                    for try await hrData in api.startHrStreaming(identifier) {
                        for sample in hrData.samples {
                            print("心率: \(sample.hr), RR: \(sample.rrsMs)")
                        }
                    }
                } catch {
                    print("心率流错误: \(error)")
                }
            }
        }
    }

    func deviceConnected(_ polarDeviceInfo: PolarDeviceInfo) {
        print("已连接: \(polarDeviceInfo)")
    }

    deinit {
        hrTask?.cancel()
    }
}
```

## 七、常见使用场景

### 7.1 采集 ECG（以 H10 为例）

```kotlin
// 1. 创建 API 时启用在线流功能
// 2. 连接并等待 FEATURE_POLAR_ONLINE_STREAMING 就绪
// 3. 查询可用设置 → 开始流式采集

scope.launch {
    // 查询 ECG 支持的采样参数
    val settings = api.requestStreamSettings(deviceId, PolarBleApi.PolarDeviceDataType.ECG)

    // 开始 ECG 流（返回 Flow<PolarEcgData>）
    api.startEcgStreaming(deviceId, settings).collect { ecgData ->
        for (sample in ecgData.samples) {
            // sample.voltage 为微伏值
            Log.d("ECG", "电压: ${sample.voltage} µV")
        }
    }
}
```

> **H10 重要提醒**：停止 ECG/ACC 流之前不要取下传感器，否则设备会一直耗电直到没电。务必在 App 中主动停止流并断开连接。

### 7.2 离线录制

```kotlin
// 创建 API 时加入 FEATURE_POLAR_OFFLINE_RECORDING
// 等待 bleSdkFeatureReady 返回该 Feature

scope.launch {
    // 查看设备支持哪些离线数据类型
    val types = api.getAvailableOfflineRecordingDataTypes(deviceId)

    // 查询 ACC 离线录制的可用参数
    val settings = api.requestOfflineRecordingSettings(
        deviceId,
        PolarBleApi.PolarDeviceDataType.ACC
    )

    // 开始离线录制（即使 BLE 断开，设备仍会继续录）
    api.startOfflineRecording(deviceId, PolarBleApi.PolarDeviceDataType.ACC, settings)

    // ... 一段时间后 ...

    // 停止录制
    api.stopOfflineRecording(deviceId, PolarBleApi.PolarDeviceDataType.ACC)

    // 列出并读取录制文件
    val entries = api.listOfflineRecordings(deviceId)
    for (entry in entries) {
        val data = api.getOfflineRecord(deviceId, entry)
        // 处理 data
    }
}
```

详见：[SdkOfflineRecordingExplained.md](./documentation/SdkOfflineRecordingExplained.md)

## 十、注意事项与已知问题

### 通用

1. **Feature 必须先启用**：实例化时未声明的 Feature，对应 API 无法使用。
2. **等 Ready 再调用**：`bleSdkFeatureReady` 回调触发后再开始采集。
3. **记得 shutDown**：Activity/Service 销毁时释放 SDK。
4. **真机调试**：BLE 功能无法在模拟器上测试。

### H10 特别注意

| 问题 | 处理方式 |
|------|----------|
| 取下传感器后 45 秒断连 | 读取内置录制时保持佩戴 |
| ECG/ACC 未停止导致耗电 | App 中主动 `stopXxxStreaming` 并断开连接 |

### Verity Sense

| 问题 | 处理方式 |
|------|----------|
| 旧固件 PPG 采样率显示错误 | 升级到固件 2.1.0+，或启用 SDK Mode |

完整列表：[KnownIssues.md](./documentation/KnownIssues.md)

## 十四、快速排错

| 现象 | 可能原因 | 建议 |
|------|----------|------|
| 扫描不到设备 | 权限未授予 / 蓝牙未开 | 检查权限弹窗与系统蓝牙开关 |
| 连接成功但无数据 | 未等 `bleSdkFeatureReady` | 在回调里再调用 streaming API |
| `ERROR_NOT_SUPPORTED` | 设备不支持该功能 | 查产品文档，调用 `getAvailableXxx` 确认 |
| iOS 编译报错 RxSwift | 使用了 8.0 前的旧代码 | 按 MigrationGuide8.0.0 改为 async/await |
| H10 突然断连 | 传感器已从胸带取下 | 保持佩戴或先读完离线数据 |

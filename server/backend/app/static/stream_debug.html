Phase 1–3：数据接入 & HRV & 状态分类

检查 Android 推流入库（Phase 1）、HeartPy HRV 分析（Phase 2）、EWMA 基线与焦虑分分类（Phase 3）。

你在看什么？
  • 手机每 60–120 秒 发一包 RR 间期数据（ms）
  • Phase 1 门控：n_clean < 20 直接拒收，页面上看不到被拒的包
  • Phase 2 分析：HeartPy quotient-filter 清洗 → 时域/频域/Poincaré/SampEn/DFA → 写入 hrv_analysis_results
  • Phase 2 质量门控：清洗后 n_clean < 30 或 覆盖率 < 60% → 不产出 HRV 结果
  • Phase 3 基线：Redis EWMA（α=0.05），≥ 50 窗口后成熟，才开始有效分类
  • Phase 3 分类：9 指标加权 z-score → 0–100 焦虑分 + 状态标签（calm / elevated / anxious 等）
